# Glossary

| Term | Meaning |
| --- | --- |
| ANN | Approximate nearest neighbour search. Fast vector search that trades a little recall for speed. |
| Bi-encoder | Model that embeds query and document separately. Used for vector search. |
| Bitemporal | A fact stores both valid time (true in the world) and system time (when recorded). |
| Blocking | In entity resolution, compare only candidates that share a key. |
| BM25 | Keyword ranking function. Strong on exact terms. |
| Chunk | The unit of text you embed and retrieve. |
| Cross-encoder | Model that reads query and document together. Used for reranking. |
| Cypher / GQL | Query languages for property graphs. GQL is the ISO standard. |
| Embedding | A vector that represents meaning. |
| Entity resolution | Deciding which records or mentions are the same real thing. |
| HNSW | Graph-based index for ANN vector search. |
| IRI / URI | Global identifier for a thing or relation in RDF. |
| LPG | Labelled property graph. Nodes and edges with labels and properties. |
| Named graph | A set of triples with its own ID. Used for provenance. |
| Ontology | Formal definition of types, relations, and rules. |
| OWL | Web Ontology Language. Logic on top of RDFS. |
| Provenance | The record of where a fact came from and how. |
| RDF | Resource Description Framework. Data as subject-predicate-object triples. |
| RDF-star | RDF extension for statements about triples. |
| Reranker | Second-stage model that rescores retrieved results. |
| RRF | Reciprocal rank fusion. Merges ranked lists by rank, not score. |
| SHACL | Shape language that validates RDF data. |
| SKOS | Vocabulary for taxonomies and concept schemes. |
| SPARQL | Query language for RDF. |
| Triple | One RDF fact: subject, predicate, object. |
| Turtle | Human-readable RDF format. |
