# Reference stack and reading list

The titles below come from general knowledge, not a live check. Confirm current versions and project status before you build on a tool.

## Books and courses

| Title | Use it for | Modules |
| --- | --- | --- |
| *Networks, Crowds, and Markets* (Easley, Kleinberg) | Graph theory intuition | 0, 9 |
| *Graph Databases* (Robinson, Webber, Eifrem) | Property graph modelling | 1 |
| *Semantic Web for the Working Ontologist* (Allemang, Hendler, Gandon) | RDF, RDFS, SHACL | 2, 3 |
| *Knowledge Graphs* (Hogan and others, 2021) | Broad survey, free online | 2, 3, 7 |
| Stanford CS224W (Leskovec) | Graph algorithms and graph ML | 9 |
